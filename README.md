# HamArc — помехоустойчивый архиватор

Консольный архиватор без сжатия, объединяющий файлы в формат `.haf`. Данные кодируются с использованием кодов Хэмминга для обнаружения и исправления ошибок.

Лабораторная работа №4 по C++ в ИТМО.

## Возможности

- Создание архива и просмотр списка файлов.
- Извлечение всех или выбранных файлов.
- Добавление и удаление файлов, объединение архивов.
- Кодирование и декодирование данных с проверкой ошибок.

## Что изучено и применено

- Коды Хэмминга и побитовая обработка данных.
- Проектирование бинарного формата и работа с файловыми потоками.
- Декомпозиция на архиватор, кодировщик и парсер аргументов.
- Классы, инкапсуляция и обработка исключений.
- Повторное использование библиотеки аргументов и GoogleTest.

## Сборка

Требуются компилятор с поддержкой C++23 и CMake 3.20 или новее. Команды выполняются из корня репозитория. При первой настройке CMake загружает тестовые или сетевые зависимости, поэтому нужен интернет.

```sh
cmake -S . -B build
cmake --build build --parallel
```

В Visual Studio и других генераторах с несколькими конфигурациями добавьте `--config Debug` к команде сборки. Исполняемые файлы в таком случае могут находиться в подкаталоге `Debug`.

## Использование

```sh
./build/bin/hamarc --create --file=example.haf first.txt second.txt
./build/bin/hamarc --list --file=example.haf
./build/bin/hamarc --extract --file=example.haf
```
